Detailed Description

TCP accept-loop server base class for OCP.1 connections.

Runs a background thread that blocks on accept() and calls the pure-virtual createConnectionObject() each time a new TCP client connects. The concrete subclass (NanoOcp1Server) implements createConnectionObject() to return a NanoOcp1Client peer wired to the server's callbacks.
