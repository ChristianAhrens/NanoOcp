Detailed Description

Two-dimensional address of a DS100 remote object.

  • pri (primary): channel number — matrix input (1–128), output (1–64), function group (1–32), or reverb zone (1–4).
  • sec (secondary): only used for two-dimensional parameters, e.g. mapping area index for CoordinateMapping or output channel for MatrixNode.
  • Fields equal to sc_INV (0) mean "not used".
